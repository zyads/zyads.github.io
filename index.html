● run #001 · 2026-08-01 · genesis commit

This page publishes itself

Every post in this log starts life as a GitHub Issue on this repo. When I open one titled post: ... (or label one post), a GitHub Action wakes up: it renders the issue body into the HTML you are reading right now, commits the change back to master as a bot, redeploys the site through GitHub Pages, then comments the live URL on the issue and closes it.

No CMS, no database, no build framework — the pipeline is one workflow file and one stdlib-only Python script. The blog is a build artifact, every entry links back to the issue it was born as, and the whole edit history is public. This entry is the only one that was committed by hand; it had to exist before the machine could write the rest.
